# 5252 Downloader
![Downloads](https://img.shields.io/github/downloads/MrK7891/downloader-5252/total)
A simple, multi-threaded downloader written in C++.

## 🚀 Features
- 4-thread concurrent downloading (supports HTTP Range).
- Native Windows GUI (built with WinINet & Win32 API).
- No installation required, just run the `.exe`.
- Lightweight and fast.

## 🛠️ How to Use
1. Download the latest `5252downloadloader.exe` from the [Releases](../../releases) page.
2. Open the executable.
3. Paste a valid HTTP/HTTPS direct download link into the input box.
4. Choose where to save the file and click **"开始下载"** (Start Download).

## ⚠️ Note
Because it is an unsigned personal project, Windows Defender or antivirus software might flag it as a false positive. You can safely ignore it or build from the source code.
